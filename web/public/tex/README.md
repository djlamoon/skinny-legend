# Textures

Original textures generated for Skinny Legend with an AI image generator (no stock or Pinterest images), then resized and compressed to WebP. Total is about 108 KB.

| File | Used for |
| --- | --- |
| `latex.webp` (1024², 47 KB) | Hot-pink glossy latex hero backdrop |
| `liquid-chrome.webp` (640², 49 KB) | Camera orb, avatars, restaurant photo fallback, calorie tube |
| `brushed-pink.webp` (800×450, 12 KB) | Brushed pink metal buttons, active tab, your chat bubbles |

Silver chrome, the halftone dots and the lips mark are pure CSS/SVG. See `src/styles/tokens.css`.
