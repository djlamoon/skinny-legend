# Skinny Legend — web 💅

Next.js (App Router, TypeScript) website for Skinny Legend: snap your plate, get calories, macros and vitamins, and log your day. The look is Y2K: hot pink and liquid chrome.

```bash
cd web
npm i
cp .env.example .env.local   # optional, add XAI_API_KEY for real analysis
npm run dev                   # http://localhost:3000
```

See the root [README](../README.md#-website-web) for features, env vars and deploy steps.
